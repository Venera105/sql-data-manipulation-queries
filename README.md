# Сборник практических мини-проектов на SQL (MySQL) 🗄️

В данном репозитории представлены решения двух практических мини-проектов, выполненных в рамках обучения. Скрипты демонстрируют навыки проектирования баз данных, манипуляции данными (DML/DDL), а также расчета продуктовых и коммерческих метрик.

---

## 📊 Мини-проект 1: Анализ активности пользователей и продуктовых метрик

**Бизнес-задача:** Анализ логов активности пользователей на сайте, расчет вовлеченности в просмотр рекламы и удержания.

**Какие аналитические задачи решены в коде:**
1. Подсчет уникальной аудитории (DAU/MAU за период).
2. Поиск самых активных пользователей по объему потребления контента.
3. Расчет **LT (Lifetime)** — продолжительности присутствия каждого пользователя на сайте.
4. Сложная фильтрация: расчет среднего количества просмотров рекламы с ограничением по минимальной активности (от 5 разных дней).

**Используемый стек:** Конструкции `COUNT(DISTINCT)`, `HAVING`, `DATEDIFF` (или операции с датами), вложенные подзапросы, группировки.

👉 *Код решения находится в файле:* `miniproject1_user_analytics.sql`

---

## 💼 Мини-проект 2: Анализ коммерческих продаж и эффективности персонала

**Бизнес-задача:** Настройка реляционной связи между таблицей проданных товаров (`T_TAB1`) и справочником сотрудников (`T_TAB2`) для оценки личной эффективности менеджеров.

**Какие аналитические задачи решены в коде:**
1. Базовый аудит продаж: подсчет уникальных категорий, объемов и выручки по конкретным типам товаров (мобильные телефоны, клавиатуры, принтеры).
2. HR-аналитика: фильтрация штата по возрасту и уровню заработной платы, расчет агрегатов (MIN/MAX/AVG).
3. Анализ эффективности: объединение таблиц (`JOIN`) для расчета личной выручки каждого продавца.
4. Поиск «узких мест»: выявление сотрудников, у которых отсутствуют продажи (поиск пропусков через `LEFT JOIN`).

**Используемый стек:** `INNER JOIN`, `LEFT JOIN` для поиска неактивных сотрудников, `SUM`, `AVG`, `WHERE` фильтрация.

👉 *Код решения находится в файле:* `miniproject2_sales_and_hr.sql`

Все запросы структурированы, снабжены комментариями и готовы к импорту в MySQL Workbench, DBeaver или любой другой SQL-клиент.
